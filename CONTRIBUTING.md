# Contributing

We welcome contributions to this Florida HVAC regulations guide. Whether you're a licensed contractor, building inspector, homeowner, or HVAC industry professional, your expertise can help make this resource more accurate and useful.

## How to Contribute

### Corrections

If you find inaccurate information:
1. Open an issue describing the error
2. Include the correct information and a reference source (statute, code section, DBPR rule)
3. Or submit a pull request with the correction

### New Content

We're looking for contributions in these areas:
- County-specific permit procedures and fees
- Recent code changes and their practical impact
- Real-world inspection experiences
- Homeowner protection case studies (anonymized)

### Updates

Regulations change. Help us stay current:
- Florida Building Code updates (new edition cycles every 3 years)
- DOE efficiency standard changes
- DBPR rule changes
- County-level process changes

## Guidelines

- All content must be factual and cite official sources where possible
- Write for a general audience (homeowners and contractors)
- Keep formatting consistent with existing documents
- No promotional content or contractor recommendations

## About This Project

This guide is maintained by [AC Repair Today](https://ac-repair.today), a licensed HVAC contractor in South Florida. We believe informed homeowners make better decisions and that transparency about regulations benefits the entire industry.
