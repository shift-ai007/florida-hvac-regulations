# Florida Building Code - HVAC Requirements

Florida adopted the 8th Edition (2023) Florida Building Code, which incorporates the International Mechanical Code (IMC) with Florida-specific amendments. These codes govern how HVAC systems must be designed, installed, and inspected.

## Minimum Efficiency Standards (2026)

The Department of Energy updated minimum efficiency standards effective January 1, 2023, with additional increases phased in. Florida falls in the "South" region (DOE Southeast Region).

### Residential Split Systems

| System Type | Minimum Efficiency (South Region) |
|------------|----------------------------------|
| Central AC (split) | 15 SEER2 / 11.7 EER2 |
| Heat Pump (split) | 15 SEER2 / 11.7 EER2 / 7.5 HSPF2 |
| Single Package AC | 14 SEER2 / 11.0 EER2 |
| Single Package Heat Pump | 14 SEER2 / 11.0 EER2 / 6.7 HSPF2 |

**Note**: SEER2 replaced SEER as the rating standard. SEER2 values are roughly 4-5% lower than equivalent SEER values due to updated testing procedures. A 15 SEER2 unit is roughly equivalent to the old 16 SEER.

### Mini-Split / Ductless Systems

| Capacity | Minimum Efficiency |
|----------|-------------------|
| < 65,000 BTU | 15 SEER2 |
| >= 65,000 BTU | Follows commercial standards |

## Duct Requirements

### Duct Insulation

Florida Building Code requires:

- **Supply ducts in unconditioned spaces**: Minimum R-6 insulation (R-8 recommended)
- **Return ducts in unconditioned spaces**: Minimum R-6 insulation
- **Ducts in conditioned spaces**: No insulation required but recommended
- **Duct sealing**: All joints and seams must be sealed with mastic or UL 181-rated tape

### Duct Testing

- **New construction**: Duct leakage testing required. Maximum 4 CFM25 per 100 sq ft of conditioned floor area (total leakage) or 3 CFM25 per 100 sq ft (leakage to outside)
- **Replacement systems**: Testing may be required depending on jurisdiction and scope of duct modification

### Duct Materials

- Flex duct: Maximum 15 feet per run without support points
- Rigid duct: Sheet metal gauge per SMACNA standards
- Duct board: Must be UL 181-rated
- All duct materials must be labeled with flame spread and smoke development ratings

## Load Calculations

### Manual J (Load Calculation)

Every new HVAC installation in Florida requires a Manual J load calculation:

- Accounts for home size, insulation, windows, orientation, occupancy
- Must use ACCA-approved software or manual worksheets
- Determines correct system size in tons/BTU
- **Common mistake**: Oversizing. A system that's too large short-cycles, creates humidity problems, and wastes energy. Florida's humidity makes correct sizing critical.

### Manual S (Equipment Selection)

After Manual J determines the load:
- Equipment must be selected to match the calculated load (within manufacturer tolerance)
- Equipment cannot exceed 115% of the cooling load (prevents oversizing)
- Latent capacity (dehumidification) must be considered for Florida's humid climate

### Manual D (Duct Design)

- Duct sizing must be calculated, not guessed
- Each supply register must deliver the correct CFM for the room
- Return air must be adequate (common failure point)
- Static pressure must be within equipment manufacturer limits

## Refrigerant Regulations

### EPA Section 608

All HVAC technicians handling refrigerants must hold EPA 608 certification:

| Certification | Covers |
|--------------|--------|
| Type I | Small appliances (< 5 lbs refrigerant) |
| Type II | High-pressure (R-410A, R-22) - most residential |
| Type III | Low-pressure (chillers) |
| Universal | All of the above |

### R-22 Phase-Out

- R-22 (Freon) production and import banned since January 1, 2020
- Existing systems can continue operating but repairs require reclaimed R-22
- R-22 prices have increased dramatically - often makes repair uneconomical
- Drop-in replacements (R-407C, R-422D) require system compatibility verification

### R-410A Transition

- R-410A is being phased down under the AIM Act (2024+)
- New systems transitioning to R-454B (Puron Advance) and R-32
- R-454B classified as A2L (mildly flammable) - requires updated installation practices
- Technicians need training on A2L refrigerant safety

## Electrical Requirements

- Dedicated circuit required for outdoor condenser unit
- Disconnect switch within sight of outdoor unit (NEC 440.14)
- Circuit breaker sized per manufacturer specifications
- Minimum 14 AWG wire for most residential AC circuits (10 AWG for larger systems)
- GFCI protection not required for HVAC equipment (but required for receptacles in equipment rooms)

## Condensate Drainage

Florida code requires:

- Primary condensate drain: Minimum 3/4" PVC, properly sloped
- Secondary drain or float switch: Required to prevent overflow
- Drain termination: Must discharge to an approved location (not onto walkways)
- P-trap or check valve on negative pressure air handlers
- Condensate pumps: Allowed when gravity drain isn't possible
